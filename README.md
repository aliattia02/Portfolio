## Featured Projects

### [DiaTwin — Clinical AI Insulin Dosing System](https://dia-twin.vercel.app)
**M.Sc. Thesis + Live Product · 2023–2025**

A clinically validated AI platform for personalised insulin dosing support, built across web and mobile.

- **Clinical validation:** 8.7/10 utility score — Prof. Dr. Klaus Parhofer, LMU Munich. TRL 4–5
- **Regulatory pathway:** CE Class IIa + DiGA Fast-Track planned
- **PK/PD engine:** Dual-platform gamma engine (Python + TypeScript, bit-for-bit identical) — 14 insulin analogues per AWMF S3 guideline 057-013
- **Real-world data:** RL layer trained on 50,000+ real meal-outcome pairs; CGM integration via LibreLinkUp/Abbott
- **Stack:** `Python` `TypeScript` `React` `React Native` `Flask` `MongoDB` `TensorFlow` `scikit-learn` `Gemini API`

### [Morafek CareMate — FHIR-Native Care Coordination Platform](https://morafek-care-mate.vercel.app)
**Full-Stack · Production · 2024**

A care coordination platform with a manually implemented FHIR R4 backend — no pre-built FHIR server.

- **Architecture:** Python/Flask backend + React Native (Expo) mobile app; 35+ REST endpoints across 5 modules
- **FHIR depth:** 6 R4 resource types implemented from scratch — Observation, Encounter, Condition, DocumentReference, Communication, Bundle
- **Clinical features:** Automated severity thresholds (HR/glucose/SpO₂/BP), LOINC-coded documents, ICD-10-GM visits, patient consent model, offline SQLite queue
- **Standards:** LOINC (7 codes), ICD-10-GM, FHIR R4 Bundle export, OMOP CDM-ready schema
- **Stack:** `Python` `Flask` `React Native` `Expo` `SQLite` `Render` `Vercel`
